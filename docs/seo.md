# Référencement

Domaine canonique : https://myoctogone.com. URL canoniques et sitemap utilisent une barre oblique finale.

- `/robots.txt` autorise l’exploration et indique `/sitemap-index.xml`.
- `/sitemap.xml` est généré depuis les données des huit filiales et des projets vérifiés, avec versions FR/EN et alternatives réciproques.
- Les erreurs, maintenance, hors ligne, projets illustratifs et mentions légales encore incomplètes portent `noindex` et ne figurent pas dans le sitemap. Leur exploration reste autorisée pour que les moteurs lisent cette directive.
- JSON-LD : Organization, WebSite, WebPage, ContactPage/AboutPage, BreadcrumbList, CreativeWork (projets vérifiés), Service (filiales). Pas de notes, d’avis ni d’immatriculation inventés.
- Métadonnées sociales et image de partage 1200 × 630.

Après mise en ligne : vérifier le domaine dans Google Search Console avec l’accès du propriétaire, soumettre https://myoctogone.com/sitemap-index.xml, contrôler les pages indexées et les Core Web Vitals. Aucune balise de vérification fictive n’a été ajoutée. GitHub Pages gère HTTPS et les réponses HTTP ; ses réglages DNS ne sont pas modifiés par ces fichiers.

Références : https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls et https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap.
